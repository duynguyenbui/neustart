# Always Explain German Grammar

- **Always Explain Grammar**: When correcting German text, assisting with German writing, or working on German exercises, always explain the underlying grammar rules.
- **Detailed Explanations**: Explain the reasons behind specific word orders, verb conjugations, cases (Nominativ, Akkusativ, Dativ, Genitiv), prepositions, or structures used, rather than just providing corrections or answers.
- **Explanation Language**: Provide the grammar explanations in Vietnamese so that the user can easily understand.
- **Explaining Noun Genders**: When explaining how to remember the gender of a German noun (der, die, das), always categorize by:
  1. **Suffixes** (e.g., -er/-ismus for der, -e/-ung for die, -chen/-ment for das).
  2. **Meaning** (e.g., biological gender, days/months).
  3. **Color-coding**: Recommend the standard color system (Blue = der, Red/Pink = die, Green = das) to help the user visualize and memorize.
