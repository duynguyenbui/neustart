# No Redundant H1 for Obsidian Notes

**Context:** The user is using Obsidian to manage this knowledge vault. In Obsidian, the filename of the note is automatically displayed as an inline Title/Header at the top of the file view.

**Rule:** 
- When creating or modifying a markdown file, DO NOT add a top-level Heading 1 (`# Title`) at the very beginning of the file if it merely repeats the filename or note title.
- Start directly with the content or with secondary headings (`##`) to avoid redundant, duplicated titles in the UI.
