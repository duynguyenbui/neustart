## Cách dùng Cursor

* Dùng Cursor trước cho autocomplete, sửa lỗi nhỏ, refactor nhẹ.
* Chỉ hỏi ChatGPT khi cần giải thích, thiết kế kiến trúc, debug khó, review logic.
* Khi đang flow code, ưu tiên Cursor để tiết kiệm quota acc.

## Cách reset

* Không reset cố định theo ngày.
* Nếu acc đang dùng bị limit:

  1. Chuyển qua Cursor nếu task còn đơn giản.
  2. Nếu cần AI mạnh hơn, chuyển sang acc tiếp theo.
  3. Chỉ reset khi Cursor không đủ và acc khác cũng không tiện dùng.

## Thứ tự reset

* Lượt 1: Acc 1 → Acc 2 → Acc 3
* Lượt 2: Acc 1 → Acc 2 → Acc 3

## Rule ngắn gọn

Cursor là đệm chính. Acc nào bị limit thì chuyển Cursor hoặc acc khác trước. Chỉ reset khi thật sự cần. Reset đều theo vòng: **1 → 2 → 3 → 1 → 2 → 3**.
